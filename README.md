# Armonia-Organica
*Armonía Orgánica* es un emprendimiento enfocado en la venta de abono orgánico por kilogramos a un valor de *$7.000 COP por kilo. La plataforma permite a los usuarios calcular el costo exacto según su presupuesto, recibir orientación mediante un **Chatbot de atención, obtener recomendaciones agrónomas personalizadas a través de un modulo IA
